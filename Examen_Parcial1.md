# Examen Parcial 1: Tecnologías actuales en Inteligencia Artificial

**Área profesional elegida:** Inteligencia Artificial (IA)

## Introducción

La Inteligencia Artificial es un área profesional que permite crear sistemas capaces de aprender de datos, reconocer patrones, generar contenido y apoyar la toma de decisiones. Para este trabajo seleccioné cinco tecnologías actuales que aparecen con frecuencia en proyectos y vacantes de Machine Learning e IA.

---

## 1. Python

![Logo de Python](img/python.png)

### Uso principal
Python es un lenguaje de programación muy utilizado en Inteligencia Artificial y Ciencia de Datos. Se usa para preparar datos, entrenar modelos, automatizar procesos y desarrollar aplicaciones de Machine Learning.

## 2. PyTorch

![Logo de PyTorch](img/pytorch.png)

### Uso principal
PyTorch es un framework de Machine Learning y Deep Learning utilizado para investigar, entrenar y desplegar modelos de inteligencia artificial. Es especialmente utilizado en visión por computadora, procesamiento de lenguaje natural y IA generativa.

### Vacante o compañía que la utiliza
La vacante de **Machine Learning Engineer - Computer Vision (Remote)** en México solicita experiencia con Python, scikit-learn, PyTorch y Keras.

- [Vacante real: Machine Learning Engineer - Computer Vision - LinkedIn](https://mx.linkedin.com/jobs/view/machine-learning-engineer-computer-vision-remote-at-hire-feed-4463355809)
- [Sitio oficial de PyTorch](https://pytorch.org/)

## 3. TensorFlow

![Logo de TensorFlow](img/tensorflow.png)

### Uso principal
TensorFlow es una plataforma de Machine Learning que permite construir, entrenar y ejecutar modelos de IA. Puede utilizarse para clasificación, predicción, visión por computadora, procesamiento de datos y otros proyectos de aprendizaje automático.

### Vacante o compañía que la utiliza
La vacante de **Data Scientist - AI/ML (Remote)** en México solicita experiencia con Python y librerías o frameworks como scikit-learn, TensorFlow o PyTorch.

- [Vacante real: Data Scientist - AI/ML - LinkedIn](https://mx.linkedin.com/jobs/view/data-scientist-ai-ml-remote-at-quik-hire-staffing-4461010797)
- [Sitio oficial de TensorFlow](https://www.tensorflow.org/)

## 4. scikit-learn

![Logo de scikit-learn](img/scikit_learn.png)

### Uso principal
scikit-learn es una biblioteca de Machine Learning para Python. Permite trabajar con algoritmos de clasificación, regresión, agrupamiento, reducción de dimensionalidad, preparación de datos y evaluación de modelos.

### Vacante o compañía que la utiliza
La vacante de **Data Scientist - AI/ML (Remote)** en México incluye scikit-learn entre las herramientas requeridas para desarrollar modelos de Machine Learning.

- [Vacante real: Data Scientist - AI/ML - LinkedIn](https://mx.linkedin.com/jobs/view/data-scientist-ai-ml-remote-at-quik-hire-staffing-4461010797)
- [Sitio oficial de scikit-learn](https://scikit-learn.org/)

## 5. Hugging Face Transformers

![Logo de Hugging Face](img/huggingface.png)

### Uso principal
Transformers es una biblioteca de Hugging Face utilizada para trabajar con modelos de IA previamente entrenados y modelos de última generación. Se puede utilizar en tareas de texto, visión, audio, video y modelos multimodales.

### Vacante o compañía que la utiliza
Una vacante de **AI Engineer en Ciudad de México**, publicada por SDG Group en LinkedIn, menciona experiencia práctica con IA generativa, LLMs, Hugging Face y Transformers.

- [Vacante real: AI Engineer - SDG Group - LinkedIn](https://mx.linkedin.com/jobs/view/ai-engineer-at-sdg-group-4456515952)
- [Documentación oficial de Transformers](https://huggingface.co/docs/transformers/index)

## Comparación rápida

| Tecnología | Tipo | Uso principal |
|---|---|---|
| Python | Lenguaje | Programación, datos y desarrollo de IA |
| PyTorch | Framework | Deep Learning y entrenamiento de modelos |
| TensorFlow | Plataforma/Framework | Creación y despliegue de modelos de ML |
| scikit-learn | Biblioteca | Machine Learning clásico y análisis predictivo |
| Hugging Face Transformers | Biblioteca | LLMs, texto, visión, audio y modelos multimodales |
